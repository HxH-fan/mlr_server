# ML Resolver — Асинхронный сервис с самообучающейся моделью

Высокопроизводительный сервис на Python, предоставляющий ML-предсказания в реальном времени.  
Система самостоятельно анализирует свою точность и автоматически запускает процесс дообучения при снижении качества прогнозов.

## Ключевые особенности

- **Асинхронная архитектура** на `asyncio` с приоритетной очередью запросов
- **ML-движок** с системой автоматического ретрейнинга
- **Метрики качества** в реальном времени
- **Персистентность** данных через SQLite и JSON
- **Интеграция** со сторонними приложениями через HTTP API

## Технологический стек

- **Бэкенд:** Python (asyncio), SQLite
- **ML и математика:** NumPy, самописные функции (softmax, dot-product)
- **Интеграция:** HTTP API, интеграция с Lua-клиентом
- **Инструменты:** Git, JSON
